# Pink

The fight with Pink from DELTARUNE Chapter 5, playable in the browser.

Everything here was extracted from the game's own files: sprites, sounds, music, text and the fight's code, which was converted to JavaScript so it runs in a web page. The encounter starts with the short scene the game shows after you lose once, and then the whole fight plays the same way it does in the game, including the dates, the ending and the game over screen.

## Controls

You need a keyboard.

- Arrow keys: move
- Z or Enter: confirm
- X or Shift: cancel
- F4: fullscreen
- Hold Esc: back to the start screen
